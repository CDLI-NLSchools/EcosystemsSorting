# Ecosystems Sorting

A formative sorting activity for **Grade 7 STEAM, Exploring Ecosystems, Lesson 2**.
It replaces a Jamboard activity whose board format no longer works in the shell.

One shared bank of 20 factor pictures (16 biotic, 4 abiotic) cropped from the
original activity is used on five pages: Arctic, Freshwater, Coastline and
Ocean, Forest, and Interactions. On each ecosystem page the student chooses
the factors they judge belong there and arranges them freely in the scene;
the same factor can be placed in several ecosystems. The Interactions page
adds three interaction boxes (Abiotic - Abiotic, Abiotic - Biotic,
Biotic-Biotic) and a short written description.

There is no answer key and no score by design: most factors belong in more
than one ecosystem, so placement is a judgement a teacher reviews from the
student's finished scene. A summary page lists what was placed on each page
and offers Print and Copy, matching the shells' portfolio pattern. Nothing
is submitted, stored, or sent anywhere.

Single-file HTML (`index.html`); the pictures are embedded, so it works
offline. Dragging works with mouse and touch, and every action is also
available from the keyboard (Enter to place, arrow keys to move, Delete to
return a picture to the bank).
